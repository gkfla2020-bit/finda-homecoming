# FIND-A 홈커밍데이 초대장

시안 A(Midnight)를 그대로 옮긴 정적 초대장입니다. 휴대폰에서는 시안 A 화면 그대로, 컴퓨터에서는 왼쪽에 표지를 고정하고 오른쪽에서 본문을 넘겨 봅니다.

- 사이트 파일: `docs/` (GitHub Pages가 이 폴더를 배포합니다)
- 참석 응답 저장: `google-apps-script/Code.gs` (Google 스프레드시트에 붙여 넣는 코드)
- 설정 두 가지: `docs/app.js` 맨 위 `CONFIG`
  - `endpoint`: Apps Script 웹 앱 주소(…/exec). 비어 있으면 제출을 받지 않고 "준비 중" 안내만 보여 줍니다.
  - `contactPhone`: 회장 연락처(숫자만). 비어 있으면 전화·문자 버튼을 숨깁니다.

## 로컬 미리보기

```sh
node tools/dev-server.mjs   # http://localhost:4173, 파일을 저장하면 브라우저가 새로고침됩니다
node tools/check.mjs        # 휴대폰·컴퓨터 화면 캡처와 폼 동작 점검 (Chrome 필요)
python3 tools/make-images.py  # 파비콘·카카오톡 미리보기 이미지 다시 만들기
```

## Google 스프레드시트 연결

1. 새 스프레드시트를 만들고 [확장 프로그램 → Apps Script]를 엽니다.
2. `google-apps-script/Code.gs` 내용을 붙여 넣고 저장합니다.
3. [배포 → 새 배포 → 웹 앱]에서 실행 사용자 "나", 액세스 "모든 사용자"로 배포하고 권한을 승인합니다.
4. 웹 앱 URL을 `docs/app.js`의 `CONFIG.endpoint`에 넣고 다시 배포합니다.

응답은 `참석응답` 탭에 쌓이고, `요약` 탭에서 참석·미참석 인원을 셉니다. 같은 연락처로 다시 제출하면 기존 줄을 고칩니다.
